Парсер kad.arbitr.ru "Картотека арбитражных дел" и rusprofile.ru "Проверка контрагентов".

Мной разработано более 100 кликеров-парсеров. Этот парсер являтся объединением 8 разных проектов и в таком виде ни для кого не разрабатывался. Интерфейс программы собирается из отдельных тегов, при поготовке парсера под очередной проект ненужные теги скрываются и интерфейс автоматически перерисовывается, а скрытые функции становятся недоступны. Отчет Excel формируется с помошью reflection по базе, построенной на основе анемичной модели, поэтому легко подстраивается под любой запрос.

Парсер находит арбитражные дела по некоторому фильтру, собирает контакты лиц, участвующих в деле и выводит их в Excel отчет

Технологии: C# + WPF + MVVM + Selenium + HtmlAgilityPack + Interop.Excel

Функционал:
  • парсинг контактов ЛУД (email, телефоны, сайты, ФИО руководителя), данных дела (№, дата, суд, судья, истец, ответчик, сумма, последний судебный акт)
  • позволяет парсить по фильтрам, используемым на kad.arbit.ru, дополнительно есть фильтр по физическим лицам, сумме иска и категории дел
  • можно парсить вручную через интерфейс и автоматически, поддерживаются консольные команды, парсить сразу несколько запросов, подключать списки прокси, парсить только новые дела, отсекая дела из старых отчетов, автоматически контролировать за сколькот дней хранятся отчеты и логи
  • обход защит от парсинга: recapthca, блокировки по IP, динамические теги, динамический контент, плавающие теги (закрывающие кнопки), всплывающие сообщения, дедект автоматических бразуеров, защита javascript ввода данных в формы
  • поддерживается гибкое изменение формы отчета: он формируется по редактируемому excel шаблону, шаблон может использовать (без изменения кода) формулы, форматы, условное форматирование
  • многопоточный парсинг, пользователь может определить сколько загрузить бразуеров, каждый поток запускается в своем контейнере, использует собственные кукесы, user agent, прокси и другие данные, что не позволяет засечь многопоточный парсинг на сервере
  • для обхода капчи подключен сервис Anticapthca, взаимодействие осуществляется по API, по нажатию кнопки можно зайти на этот сервис и почту
  • поддерживает автонаправление отчета парсинга на email по окончанию
  • регулярно записывает прогресс на диск, можно остановить, продолжить парсинг в любой момент, продолжить с последней позиции при обрыве, смотреть отчет в ходе парсинга
  • поддерживает запись в .xlsx, .xlsxm, .csv, .json форматах
  • позволяет запоминать авторизационные данные на rusprofil.ru для использования платного доступа и парсинга контактов
  • содержит интерфейс прогресса, расчета длительности парсинга, формирует отчет и лог, содержит файл с настройками, запоминает настройки установленные в интерфейсе

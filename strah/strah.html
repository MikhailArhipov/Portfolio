Кликер анкет страховых агенств

Данный клиекер распарсивает .pdf анкеты страхователей ОСАГО и заполняет по этим сведениям анкеты на сайте страховщика для получения полиса. Работа осуществляется по 3-м разным сайтам страховщиков.

 Инструменты: C# + DNA Excel + Selenium:

  • сформирована надстройка Excel, которая формирует дополнительное меню "страхование" и меню ПКМ при загрузке файла определенной структуры,
  • кликер распарсивает .pdf файлы с использованием бесплатной библиотеки pdftotext.exe,
  • данные разбиваются и заполяется Excel файл с помощью библиотеки RegularExpressions (Regex), например
  • после на сайте заполняется анкета страхователя ОСАГО через управление браузером с помощью Selenium,

Видео работы кликера

Наиболее сложная часть, это наверное отслеживание окончания работы javascrit сайта после заполнения полей "адрес" или "VIN". В этом случае сайт связывается со своей базой и может проводить проверку долго. Посокольку оператор ожидает результаты работы кликера, то отрабатывать это надо четко. Для отслеживания использовалась библиотека Selenium.Support, применялся ряд решений, например, эта фукнкция вводит значение в один тег xPath и отслеживает успешность по появлению второго тега checkXpath. А для скролинга по странице используется javascript

Также на одном из сайтов требовалось указать пол страхователя, что не было в анкете. Для определения пола использовалась функция определения пола по окончанию отчества, которая правда не дает 100% результата, но он и не был обязательным, поскольку сами операторы ошибаются чаще

Разработный кликер, существенно упрощает работу страхового агента и уменьшает вероятность ошибки.

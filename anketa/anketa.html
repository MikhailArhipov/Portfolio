Интерактивная анкета для проведения первичной оценки по системе Lockout Tagout

Разрабатывалась мной при работе в 2-х компаниях, проводивших проекты по системе Lockout Tagout, я в них возглавлял это направление.

Инструменты: VBA.

  • Содержит макросы добавления строк, листов, вставки фотографий из файла ↓

  • проверку содержимого полей, условное форматирование ↓

  • ниспадающие списки ↓

  • инструкцию по работе

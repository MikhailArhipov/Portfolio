Скрипт автоматического занесения платежей из онлайн магазинов ozon, wildberries и goods в Мой склад

Довольно нужное решение, поскольку невозможно вести аналитику продаж не понимая почем продается твой товар, но это решение отсутсвует на рынке. Работа была интересна тем, что отчеты с трех площадок выполненны с разной структурой, в виде API и Excel отчетов, и занести их следовало в уже действующий магазин по отгрузкам за прошедший год и ежедневное обновление, так чтобы онлайн WMS Мой склад сам считал обороты, затраты, оплаченные отгрузки и возвраты. Поскольку управление Мой склад ведется вручную и не все платежи имеют привязку к заказу, то скрипт разработан в 2-х версиях, для автоматической работы с Сrone и полуавтоматического занесения с выбором платежа.

Инструменты: PHP + CURL + JS:

  • получает данные по API ozon и wildberries о транзакциях, и из excel файлов по goods,
  • данные импортируются c помощью библиотек Curl, PHPExcel и сводятся в единый массив транзакций (пример по goods↓)

  • Скрипт поставлен на crone и обрабатывает каждую дату последовательно
  • Ведется лог, есть ini файл с настройками, простой интерфейс с js кнопками

  • После получения данных о платежах, ищется к чему они должны быть привязаны в Мой склад

  • Ну а после все деньги перечисленные клиенту попадают во входящий платеж, а затраты в исходящий, платеж привязывается к отгрузкам и возвратам, результаты записываются в текстовый и табличные логи. Поскольку на сервере и так много всяких cкриптов, все формы свел в один .php файл, а передачу данных между формами сделал через POST запросы с сериализаций где данных много. Сейчас я для этой задачи восновном применяю переменную $_SESSION

По результатам этой работы вскрылось множество особенностей работы с онлайн магазинами, зависшие по оплате отгрузки, продажи с отрицательной рентабельностью, неправильное отражение налогой базы в отчетности, часть функций бухгалтера взял на себя WMS, в связи счем руководством магазина было принято решение о замене бухгалтера.

Это один из группы скриптов, также совместно с этим решением были разработаны скрипты синхронизации заказов, отгрузок, возвратов, с магазинами goods, yandex, ozon, wildbereies. Скрипты разбивки комплектов, перемещения остатков между складами, контроля цен. Excel DNA надстройка для формирования цен из прайсов поставщиков.

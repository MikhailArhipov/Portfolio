PHP парсер - скрипт свода прайсов и загрузки их на Мой Склад

Инструменты: PHP + SimpleExcel + Doom модель + API Мой склад + API api.yandex.net.

Парсинг форматов: .xml, .xls, .xlsx, включая ссылки с Яндекс Диска, .csv и распарсивание .htm сайта поставщика

Импорт цен и остатков на Мой склад по API.

В парсере настраиваются ссылки откуда брать информацию (тип ссылок определяется автоматически), после данные парсятся, анализируются и сводятся в единый список, откуда уже загружаются остатки и цены в складскую программу Мой склад. Скрипт обновляет данные автоматически через Crone и вручную из администраторской панели. Особенность в том, что можно добавлять нового поставщика и настраивать данные для сопоставления (задаются линки откуда брать прайсы, зависимость сопоставления полей с Мой склад).

По данной ссылке можно попробовать интерфейс скрипта (импорт в складскую программу отключен). Логин - test, пароль - test.

Поскольку скрипт динамически настраивается, предусмотрена возможность ручного парсинга и импорта для проверки изменений. Но на сайте жестко ограничена длительность работы скриптов до 300 секунд. Для обхода этого ограничения скрипт импорта сделан в виде демон-скрипта, который каждые 70 секунд сам себя перезапускает.

Причем на сайте также запрещены почти все варианты запуска скрипта в парралельном потоке, команда pcntl_fork() отключена полностью, shell_exec, exec выбиваются быстрее чем за минуту как только теряют привязку к браузеру, а include, require, require_once работают не больше, чем запустивший их скрипт. Поэтому разработана специфическая система перезапуска скрипта и контроля дубликатов. Запуск нового скрипта сделан через curl с таймаутом 15 сек, отслеживание дубликатов через shell команду "ps -aux -p" (60 секунд - максимальное время обновления данных о запущенных процессах), сайт работает под Unix и чтобы скрипт можно было бы отлаживать на windows (где команды shell не работают), сделана альтернативная возможность отслеживания дубликатов через блокировку flock($file, LOCK_EX) чтения pid-файла

Для просмотра логов, свода парсинга добавлена возможность скачивания документы из админки, реализацию можно посмотреть по вышеуказанной ссылке. Данный скрипт разработан в марте 2023 г. и используется по настоящее время. Позволяет клиенту оперативно менять цену для улучшения спроса и соответствовать требованиям поставщика по соблюдению минимальной цены.
